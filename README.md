# 비판루프 멀티에이전트 팀 vs 단일 LLM — 조건민감 화학설계 대조실험

연세대 AX 캠프 트랙1(AI 연구 에이전트) 4주차 산출물. 앵커 논문 *The Virtual Lab*이 고정된 전제로 둔 "팀이 비판 루프를 거쳐 논의한다"는 조건을 조작변수로 이분화하고, 조건민감 화학설계 과제 20건에서 대조실험을 수행한 기록 전체다. 에이전트 호출은 228회이며 셀프시뮬레이션 프록시는 쓰지 않았다.

## 핵심 결과

판정자 루브릭 기준으로 팀(조건B)은 20건 중 18건에서 앞섰다. 평균 격차는 1.119이고 95% 신뢰구간은 0.812에서 1.406, Wilcoxon 정규근사 p=0.00019, Cohen's dz=1.61이었다.

그러나 네 갈래 후속 분석이 이 우위의 해석을 좁혔다.

| 분석 | 결과 |
|---|---|
| 조건 식별 검사 | 채점과 분리된 별도 호출에서 "어느 쪽이 팀 산출물인가"만 물었을 때 **20/20 정답** (이항검정 p=1.9e-6, 20건 모두 확신도 높음) |
| 판정자가 든 단서 | 길이가 아니라 **비판·정정·보류의 흔적**. 실제로 그 심의 잔여 표지가 조건B에 평균 3.05회 대 0.40회로 많았다(18/20, 정확검정 p=7.6e-6). 한 건은 최종 응답에 "PI"가 그대로 남았다 |
| 항목별 격차 분해 | 안전성 +2.100으로 항목별 차이 합의 **46.9%** (과반은 아니다). 팀에만 공정안전 전문가가 있는 설계 비대칭 |
| 재채점 (같은 모델, 독립 호출) | **방향은 재현, 크기는 재현 실패.** B우위 19/20(정확 p=4.8e-5), 식별 다시 20/20이나 과제 수준 Gap 상관 r=0.411(p=0.072), ICC(2,1)=0.359, 2건 부호 역전 |
| 문헌일치 객관지표 | 조건A 31/32, 조건B 31/32, 평균 격차 **0.000**. 같은 8과제 루브릭 Gap은 +1.359로 조건B 8/8 전승이었다. 단 동점 6/8로 검정력 없음 |
| 기각된 기제 | **장문 선호는 지지되지 않았다.** 조건 내부 상관이 조건A r=0.091(p=0.70), 조건B r=0.216(p=0.36)으로 모두 null이고, 합산 상관의 기울기로는 격차의 26%만 설명된다 |

H2(조건민감도가 높을수록 격차가 커진다)는 기각되고 방향까지 뒤집혔다. 회귀 기울기는 −0.266(p=0.011)이며, 순위 기반 Spearman 검정에서는 p=0.0525로 경계선에 머물렀다.

안전성 항목을 제외한 강건성 검정에서도 H1은 유지되고 H2는 여전히 반전됐다. 평균 격차 0.792, p=0.0057, dz=0.906, 기울기 −0.338이다.

**결론은 "팀이 더 낫다"도 "단일 LLM이 더 낫다"도 아니다.** 웻랩 검증 없이 판정자 점수만으로 멀티에이전트 구조의 우월성을 주장하는 평가 설계에서는, 구조가 텍스트에 남기는 흔적과 구조의 실제 효과가 분리되지 않는다.

배제하지 못한 경쟁 설명도 논문에 그대로 적었다. 팀이 실제로 더 안전한 설계를 냈을 가능성(안전 서술의 양만 재고 타당성은 재지 않았다), 판정자 자기 선호 편향(판정자가 생성 모델과 같은 계열이다), 제시 순서 편향(12대 8 불균형으로 검정력 부족), 고난도 과제 프롬프트의 정답 노출(k≥3에서 조작 변수를 프롬프트가 명시했다) 네 가지다.

## 실험 설계 요약

- 과제 20건을 조건민감도 k=1~5로 층화(각 4건)
- **조건A(단일 LLM)**: 토론 없이 1회 호출
- **조건B(비판루프 팀)**: 서로 다른 에이전트 7회 호출 — 합성화학자 초안 → Critic 비판 → 메커니즘 전문가 개선 → Critic 비판 → 공정안전 전문가 최종개선 → Critic 비판 → PI 통합
- 블라인드 채점 2라운드, 채점과 분리된 조건 식별 검사, 문헌일치 보조지표(k=1~2 한정)
- 기반 모델은 Claude 계열 단일 모델(세션 상속 방식)

## 재현

```bash
# 그림 재생성
python3 실험재현자료/그림생성.py

# 재채점 자료 생성 / 신뢰도 집계
python3 실험재현자료/재채점_생성및집계.py prepare <출력디렉토리>
python3 실험재현자료/재채점_생성및집계.py aggregate <재채점결과.json>

# 결과 시각화 웹앱
cd lab_app && pip install -r requirements.txt && python3 app.py
# http://127.0.0.1:5050
```

부트스트랩 신뢰구간은 재표본 2만 회, 난수 시드 20260731로 계산했다. 웹앱의 캐릭터 스프라이트와 바닥 타일은 Kenney(kenney.nl)의 CC0 에셋이다.

## 재현성에 관한 정직한 고지

- 멀티에이전트 실행 엔진은 독립 API 스크립트가 아니라 Claude Code의 에이전트/워크플로우 도구로 구동했다. 방법론상 "Claude 기반, 세션 상속" 방식이며 논문에도 그대로 명시했다.
- 실험실이 없어 설계된 조건으로 실제 합성을 검증하지 못했다. 주장 범위는 설계의 논리적 타당성(design plausibility)에 한정된다.
- 판정자도 언어모델이고, 응답을 생성한 모델과 같은 계열이다. 두 라운드를 돌려 재현성을 측정했으나 판정자 계열을 바꾸지 못했으므로 자기 선호 편향은 검사되지 않았다. 인간 전문가 채점과의 대조가 가장 유력한 후속 과제다.
- 문헌일치 채점 기준에 오류 2건이 있었고 화학 검토에서 사후 발견해 정정했다. 정정 전후 값을 논문 5.9절과 `lit_match.json`에 모두 남겼다.
- 과제 서술 자체에 화학적 결함이 있는 건이 3건 있다(프리델-크래프츠 다이아실화 전제, 나자로프 컨로테이토리 서술, 옥시-코프 레트로엔 경쟁 전제). 논문 7.2절에 명시했다.
- 실행 과정에서 겪은 실패(세션 사용량 한도로 2회 완주 실패, 배치 필터 결함, 빈 응답이 다음 단계로 전파된 데이터 손상)는 논문 3.6절과 `RESUME_HERE.md`에 축소 없이 기록했다.
- 참고문헌의 서지 정보(권·호·페이지)는 원문 대조가 아직 필요하다. 앵커 논문은 프리프린트로 인용돼 있으나 정식 출판본이 있다(Nature 646, 716–723, 2025, doi:10.1038/s41586-025-09442-9).
- **원고는 아직 앵커 논문의 장르를 따르지 못한다.** FOL 사슬 같은 내부 분석 도구가 본문에 남아 있고, 한계 서술이 발견 서술을 압도하며, 결과 제목이 자기 절차에 대한 판정 문장으로 되어 있다. 전수 조사와 처방은 `gap_analysis.md`에 있고 아직 원고에 반영하지 않았다.
- 그 발판 상당수는 실수가 아니라 `paper_writing_skill.md`의 체크리스트가 요구한 것이다(예: 78행이 Method 소절과 FOL 단계의 대응을 "표로 대조"하라고 지시한다). **skill 개정이 원고 개정의 선행 조건이다.**
- 91건을 다 고쳐도 타당도 결함 7개는 남는다. 특히 조건민감도 등급의 조작 점검이 실패했고(조건A 절대점수가 k와 함께 상승, r=0.447, p=0.048) 고난도 과제 프롬프트가 정답을 노출하므로, **H2를 가설 검정으로 유지할 수 있는지 자체가 미결이다.** 상세는 `gap_analysis.md` 11.3절.
